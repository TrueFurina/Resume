# 产品使用指南

**物理实验调课辅助系统** · 面向实验教学管理人员和教师

---

## 一、产品入口

| 端 | 地址 | 说明 |
|----|------|------|
| Web 前端 | `http://localhost:5173` | 教师调课对话界面 |
| API 文档 | `http://localhost:8000/docs` | Swagger 接口文档 |
| 后端服务 | `http://localhost:8000` | FastAPI 服务 |

启动方式见 [README](README.md)。

---

## 二、核心使用流程

### 步骤 1：加载数据

打开前端页面，点击右上角 **「📥 加载默认数据」**。

系统加载实验安排表（434 条排课记录），页面顶部显示：
- 排课记录数
- 教师人数
- 教室数量
- 周次范围

> 也可以点击 **「📤 上传 Excel」** 上传新的实验安排表（.xlsx/.xls）。

### 步骤 2：教师发起调课请求

在底部输入框输入调课请求，支持的说法：

| 输入示例 | 系统理解 |
|---------|---------|
| 我是吴琳，第六周的课上不了，调到下周 | 目标：第7周，教师：吴琳 |
| 调到第5周 | 目标：第5周 |
| 下周调课 | 目标：当前周+1 |
| 调到第十周 | 目标：第10周（支持中文数字） |

### 步骤 3：查看系统推荐的可用时段

系统自动进行**三重冲突筛选**：

1. **教室冲突** —— 该时段教室已被其他班占用？
2. **学生课表冲突** —— 该班学生该时段有其他课程？
3. **教师时间冲突** —— 调课教师自身该时段已有课？

筛选后输出可用时段列表（星期 × 时间段 × 教室），例如：

```
📋 第7周可用时段：
周一：
  567 · A410
  567 · A411
  ...
共 62 个空闲时段
```

### 步骤 4：教师选择时段

教师从可用时段中挑选合适的时间（系统已保证无冲突），确认后提交。

### 步骤 5：管理员审批（模拟）

- 管理员审批通过 → 手动在教务系统中修改课程安排
- 管理员驳回 → 通知教师重新选择

> ⚠️ **系统只提供分析和建议，不直接修改教务系统数据。**

## 三、时间段说明

| 节次标记 | 实际时间 |
|---------|---------|
| 567 | 13:30-15:45 |
| 678 | 15:45-18:00 |
| 91011 | 18:30-20:45 |
| 78 | 15:50-18:05 |

仅检查工作日（周一~周五）下午/晚上时段；上午和周末不安排实验课。

---

## 四、注意事项

1. **必须先在 backend 目录启动后端**：`cd backend && uvicorn app.main:app --reload`
2. 学生课表为内置数据（闽江学院张敏杰 2024-2025-2 课表），如需更换需修改 `backend/app/utils/student_data.py`
3. 实验安排表需包含「大学物理实验安排表 (周)」工作表
4. 系统识别教师支持"我是XXX"和姓名关键词两种方式

---

## 五、适用场景

- 教师临时有事需调换实验课时间
- 教务管理员需要快速评估调课可行性
- 补课安排（为缺课学生寻找不冲突时段）
- 新学期的实验排课辅助验证

## 六、不适用场景

- ❌ 学生选课（公共必修课无需选课）
- ❌ 签到考勤（已有学习通等工具）
- ❌ 实验报告批改（纸质报告为教学要求）
- ❌ 自动修改教务系统（需要人工确认）
