# 产品使用指南

**物理学科智能排课选课智能体系统**（Solo 版）· V1.0

---

## 一、产品入口

| 端 | 地址 | 说明 |
|----|------|------|
| Web 前端 | `http://localhost:5173` | 四大模块主界面 |
| API 文档 | `http://localhost:8000/docs` | Swagger 接口文档 |
| 后端服务 | `http://localhost:8000` | FastAPI 服务 |

### 启动方式

```bash
# 后端
cd backend
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000

# 前端（另一终端）
cd frontend
npm install
npm run dev
```

> 需要环境变量：`JIYUAN_LVDONG_BASE_URL`、`JIYUAN_LVDONG_API_KEY`（律动基元 LLM 凭据）

## 二、四大模块使用步骤

### 模块 1：排课调课（📅）

**适用**：教师查看课程、调课、查看冲突

1. 打开系统，自动加载实验安排表
2. **选择身份**：点击教师卡片（如"吴琳"）
3. **查看我的课程**：看到该教师全部课程，分【可调 ✅ / 不可调 ❌】
4. **发起调课**：点击课程卡片"申请调课"
5. **选目标周次**：下拉选择（第1-16周），自动筛选
6. **查看结果**：
   - 🟢 可用时段（绿色，可直接选）
   - 🚫 被排除时段（灰色，每条附原因：教室占用/学生有课/教师冲突）
   - 🤖 推荐候选方案（AI 生成 2-3 个，含理由）
7. **提交申请**：确认调课申请，状态变"待审批"
8. **管理员审批**：顶部"⚙️ 审批"入口 → 同意（提示去教务系统修改）/ 驳回（填原因）
9. 审批结果反馈教师

**自然语言调课**：在"💬 自然语言调课"输入框直接说：
- "我是吴琳，第六周的课上不了，调到下周"
- "下周三有点事，把实验课往后挪一周"
- 信息不全时系统自动追问（多轮对话）

### 模块 2：选课咨询（🎓）

**适用**：学生咨询选课资格、先修课程、学分

1. 点击顶部导航"🎓 选课咨询"
2. 输入问题，如：
   - "为什么我选不了大学物理实验课？"
   - "选物理实验需要先修什么课？"
3. 系统基于学生课表，用 LLM 回答（结论 + 原因 + 建议）

### 模块 3：实验辅导（🔬）

**适用**：学生咨询实验原理、数据处理、误差分析

1. 点击顶部导航"🔬 实验辅导"
2. 输入问题，如：
   - "扭摆法测转动惯量的误差来源有哪些？"
   - "如何计算不确定度？"
3. 系统用 LLM 回答（步骤清晰、公式正确、引用实验规范）

### 模块 4：管理员审批（⚙️）

**适用**：管理员审批调课申请

1. 点击顶部导航"⚙️ 审批"
2. 查看待审批申请列表
3. 同意 → 提示"请在教务系统中完成修改"
4. 驳回 → 填写原因反馈教师

## 四、注意事项

1. **必须先在 backend 目录启动后端**（`app` 包在该目录下）
2. **LLM 服务不稳定时**：核心流程（排课/调课筛选）由规则引擎兜底，不依赖 LLM 也能用
3. **身份选择替代登录**：演示用可视化选择，无需账号密码
4. **换学校数据**：上传该校实验安排表 + 学生课表即可，系统自动解析
5. **系统不改教务系统**：审批通过后由管理员人工在教务系统修改

## 五、适用场景

- 教师临时有事需调换实验课时间
- 管理员评估调课可行性（多班多教室冲突）
- 学生选课资格咨询（先修课/学分）
- 学生实验辅导（原理/数据处理/误差分析）
- 高校实验教学中心日常排课管理

## 六、不适用场景

- ❌ 大规模自动排课（当前做冲突筛选+候选推荐，非自动生成）
- ❌ 移动端（仅 Web）
- ❌ 教务系统双向对接（需学校接口支持）
