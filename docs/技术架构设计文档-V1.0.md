## 1. 系统定位

面向高校物理实验教学场景的 **四大模块智能体系统**，覆盖排课、选课、调课、辅导全流程，以 AI 对话降低操作门槛、以规则引擎保证结果可靠。

### 1.1 四大核心模块（评审要求）

| 模块 | 核心能力 | 实现方式 |
|------|---------|---------|
| **排课** | 冲突筛选、资源占用分析、候选时段推荐 | 规则引擎 + LLM 候选方案 |
| **选课** | 选课资格咨询、先修课程解释、学分查询 | LLM 咨询 |
| **调课** | 教师发起调课、空闲时段筛选、管理员审批 | 规则引擎 + LLM 意图解析 |
| **辅导** | 实验原理、数据处理、误差分析、报告规范问答 | LLM 咨询 + 知识库 |

### 1.2 设计原则

1. **系统知道用户是谁**：身份选择后展示名下全部课程（评审核心意见）
2. **火车票改签式交互**：先展示"我的票"，再选"改签时间"（王铮导师建议）
3. **信息透传**：每个不可选时段标注原因（评审核心意见）
4. **规则引擎兜底，LLM 增强**：核心流程不依赖 LLM 稳定性

## 3. 核心模块设计

### 3.1 调课智能体（RescheduleAgent）

**职责**：调课请求解析 + 三重冲突筛选 + 原因标注 + 候选方案

**解析策略（双轨）**：
```
规则解析（"第六周的课上不了，调到下周" → 源周6，目标周7）
    ↓ 失败时
LLM 解析（律动基元解析大白话："下周三有事，把实验课往后挪一周"）
    ↓ 信息不全时
多轮追问（系统列出缺失项，用户补充）
```

**三重冲突筛选**：

| 检查 | 依据 | 标注原因类型 |
|------|------|-------------|
| 教室占用 | 实验安排表 | `classroom_busy` |
| 学生课表 | 学生课表数据 | `student_busy` |
| 教师自身时间 | 实验安排表教师列 | `teacher_busy` |

**AI 候选方案（B3）**：LLM 从可用时段生成 2-3 个候选 + 推荐理由；LLM 不可用时规则降级（按星期去重挑 3 个）。

### 3.2 律动基元 LLM 接入（LLMIntentParser）

**接口**：OpenAI 兼容（`POST {BASE_URL}/chat/completions`）

| 配置 | 值 |
|------|-----|
| Base URL | `https://tokenrhythm.studio/v1`（环境变量 `JIYUAN_LVDONG_BASE_URL`） |
| API Key | 环境变量 `JIYUAN_LVDONG_API_KEY`（不硬编码） |
| 模型 | `deepseek-v4-flash`（默认） |

**三个 LLM 能力**：
1. `parse()` — 大白话调课意图解析（teacher/source_week/target_week/needs_followup）
2. `suggest_plans()` — 从可用时段生成多候选方案
3. `consult()` — 选课咨询（role=course_select）/ 实验辅导（role=experiment_tutor）通用问答

**容错设计**：LLM 503/超时/解析失败 → 静默降级到规则引擎，主流程不受影响。

### 3.3 数据层

| 数据 | 来源 | 结构 |
|------|------|------|
| 实验安排表 | 上传 Excel（可替换，支持多校） | 433 条排课记录（周次/星期/时段/班级/教室/教师） |
| 学生课表 | 内置 / 上传 Excel/PDF | 27 门课程（课程名/星期/节次/周次） |
| 调课申请单 | 运行内存 | 教师/课程/原时间/目标周/状态/审批意见 |

**时间归一化**：Excel 中 12 种时间格式统一映射为节次标记（567/678/91011/78），保证冲突比对正确。

## 4. 关键技术决策

| 决策 | 理由 |
|------|------|
| 规则引擎为主，LLM 增强 | 保证核心流程稳定可演示（评审：先跑通再优化） |
| 身份可视化选择，不做账号密码 | 演示友好 + 满足"系统知道用户是谁" |
| 数据驱动，各校上传总表 | 可推广（不绑定闽江大学数据） |
| 前端模板表单为主，自然语言为辅 | 评审建议模板优先，降低输入负担 |
| 申请单内存存储 | 最小闭环定位；后续可接 SQLite |

## 6. 部署

### 6.1 环境要求

- Python 3.10+（后端）
- Node.js 18+（前端）
- 环境变量：`JIYUAN_LVDONG_BASE_URL`、`JIYUAN_LVDONG_API_KEY`

### 6.2 启动

```bash
# 后端
cd backend
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000

# 前端
cd frontend
npm install
npm run dev
```

### 6.3 可推广性

- 换学校数据：上传该校实验安排表 + 学生课表即可
- LLM 服务可替换：律动基元/讯飞星火/OpenAI 兼容接口均可
- 本地化部署：模型可换本地部署模型，满足校内部署需求
