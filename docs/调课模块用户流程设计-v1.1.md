# 调课模块用户流程与页面设计 v1.1

> 物理学科智能排课选课智能体系统 · 调课模块
> 参考：火车票改签交互模式（王铮导师建议）

---

## 一、设计核心：调课 = 课程的"改签"

> 王铮导师原话：*"火车票改签页面会直接展示：我当前有哪些车票，再展示全部可选改签时间。映射到系统：调课页面应当先列出教师名下全部课程，区分可/不可调课程，再展示可选时间段。"*

**核心原则：**
1. 系统知道用户是谁（身份选择后锁定）
2. 先展示"我有哪些课"（我的课程列表）
3. 再展示"可调到哪些时间"（可用时段列表）
4. 每个不可选项说明原因（信息透传）

```
┌─────────────────────────────────────────────────────┐
│ 第1步：身份选择                                     │
│   [教师卡片列表：吴琳 / 林珠云 / 洪锦泉 / ...]       │
│   （选择"我是哪位老师"）                             │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│ 第2步：调课首页 · 我的课程                          │
│   [课程卡片列表]                                    │
│    ✅ 可调课程  ❌ 不可调课程（含原因）             │
│    （选一门要调的课）                               │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│ 第3步：模板调课单（或自然语言）                     │
│   课程：大学物理实验C（周四 567 @ A504）            │
│   目标周次：[下拉] 目标星期：[下拉] 目标时段：[下拉] │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│ 第4步：可用时段筛选结果                             │
│   ✅ 可用时段列表（绿色，可直接选）                 │
│   ❌ 不可用时段列表（灰色，附排除原因）             │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│ 第5步：确认提交 → 生成调课申请单                    │
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│ 第6步：管理员审批                                   │
│   待审批列表 → 同意（提示去教务系统改）/ 驳回（填原因）│
└──────────────────────┬──────────────────────────────┘
                       ▼
┌─────────────────────────────────────────────────────┐
│ 第7步：结果反馈给教师（通过/驳回+原因）             │
└─────────────────────────────────────────────────────┘
```

## 四、交互细节

### 4.1 信息透传原则（评审点名）

| 场景 | 展示方式 |
|------|---------|
| 课程不可调 | 卡片标注原因 |
| 时段不可用 | 列表标注排除原因 |
| 身份切换 | 顶部始终显示当前教师，可一键返回 |

### 4.2 模板优先，自然语言为辅

- 默认展示模板表单（下拉选择，零输入负担）
- 自然语言入口折叠/次要位置
- 自然语言解析失败时回退到模板引导

### 4.3 审批闭环

- 教师提交 → 状态"待审批"可见
- 管理员同意/驳回 → 教师收到结果
- 系统不直接改教务系统（边界明确）
